# Windows 原生重构

## 已完成

默认开发与发行入口切换到 WPF。主窗口包含游戏启动、世界列表、游戏下载、整合包、模组、任务、账户和设置八个页面；已有的世界管理、日志、更新、下载队列和外观接口均接入原生控件。奶蛙医学院校徽用于 Windows exe 图标与界面品牌，配色采用深蓝与奶黄。界面包含自绘标题栏、悬停与按压反馈、页面淡入、圆角输入和选择控件、拖入整合包提示、弹窗错误和操作通知。

`native/wpf/` 是 C# 界面与客户端；`native/backend.mjs` 启动 Node 游戏服务；`server/` 处理 Minecraft 元数据、加载器、Java、资源、Modrinth、CurseForge、校验与 Microsoft 登录。WPF 通过只监听 `127.0.0.1` 的随机端口访问服务，每次启动生成随机 Bearer 凭据；SSE 推送任务和账户状态。原生服务只暴露 `/api` 接口，不创建 Vite 开发服务器，也不发布网页。

这一阶段移除了浏览器界面运行时。安装引擎仍使用 Node，不能称为全 C# 单进程启动器。发行版约 35 MB，主要来自压缩的 Node 运行时；进一步降低体积需要迁移引擎或裁剪运行时。

## 构建与迁移

`scripts/build-native.mjs` 打包游戏服务和 Node，将 ZIP 与 XAML、校徽嵌入 Windows exe，通过系统 .NET Framework 编译器构建。`CquPcl.Native.csproj` 提供 SDK 项目描述，面向 net48；使用它需安装 .NET SDK 与 .NET Framework 4.8 targeting pack，并先生成引擎与 payload。

实例和配置格式沿用原项目。所有 QA 都使用新建的隔离目录，不会触碰 `.cqu-pcl/` 或已有 `release/CQU-PCL-Data/`。DPAPI 凭据可继续使用；使用其他加密方式保存的旧凭据需要重新登录。当前版本只有 Windows x64 构建路径。

原生版在解包、构建窗口和启动后端之前获取数据目录内 `.launcher-instance.lock` 的独占写句柄，并持有至窗口与后端退出。Windows 文件共享规则直接保护同一物理文件，因此路径大小写、`.` 和目录 junction 不会绕过保护；不同数据目录互不干扰。占用文件记录 PID、进程启动时间和随机命名事件。再次启动时验证拥有者并发送激活事件，让已有窗口恢复，前台弹窗也会被激活。启动期间收到的事件会保留到 WPF 就绪。程序不删除占用文件，避免删除/重建产生竞争；进程崩溃后操作系统释放句柄，下次启动自动接管。`--crypto` 助手绕过窗口保护，保持正在运行的后端可使用 DPAPI。

此保护针对当前原生启动器。非原生启动器不参与这套协议，请勿让它们同时使用原生版正在占用的数据目录。

## 验证范围

已有引擎测试覆盖元数据和准确版本安装、游戏库与资源、Fabric、下载校验与回退、取消、整合包路径防护、账户与皮肤接口。新增原生服务测试覆盖凭据验证、无网页服务、SSE 和设置写入。

下载优化增加分段并发、分段重试、Range 忽略/拒绝/错误响应回退、完整文件校验、取消后的临时文件清理、镜像校验失败回退和跨域凭据保护测试。任务删除测试验证运行中的实例锁保留到清理结束，等待中的任务删除后不会执行。下载测速覆盖多文件汇总、停滞归零和重试接收量；本地模组测试覆盖五种描述格式、文件增删替换与禁用、损坏文件和安装记录校验匹配。

原生窗口测试覆盖八个页面、四类弹窗、最小窗口、离线账户和内存设置保存、整合包识别、跨页面模拟 Microsoft 绑定、DPAPI 往返和最小化/最大化/还原。测试断言运行进程不含 Electron、WebView2 或浏览器。截图用于逐页检查。模拟登录通过不代表真实 Microsoft 应用注册已获准；实际 Minecraft 启动没有在本次 QA 中执行。

`scripts/test-single-instance.mjs` 在隔离目录启动真实 exe，验证遗留占用文件、快速重复启动、大小写与 junction 别名、唯一后端、最小化恢复、重复启动不写配置、运行中 DPAPI 助手、不同数据目录并行，以及正常/强制退出后的重启。加 `--packaged` 对发行版执行同样验证。
